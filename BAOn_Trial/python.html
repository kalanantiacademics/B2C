Password "rahasia" itu gampang ditebak! Yuk kita buat program untuk mengubah kata biasa menjadi password super kuat.

password
➡️

Seberapa Kuat Passwordmu?

Coba ketik 'password' atau nama hewan peliharaanmu.

Rahasia Password Kuat

Kita akan menggunakan Dictionary untuk mengubah huruf menjadi simbol.

'a' ➡️ '@'
's' ➡️ '$'
'o' ➡️ '0'

Dan kita akan menggunakan Loop untuk mengecek setiap huruf.

Step 1: Setup Dictionary & Input

Buat kamus simbol dan minta user memasukkan kata.

# 1. Kamus Simbol
kamus = {
  "a": "@",
  "s": "$",
  "i": "1",
  "o": "0"
}

# 2. Input Password
print("--- PASSWORD MAKER ---")
password = input("Masukkan kata: ")

Step 2: Loop & Replace

Kita cek satu-satu isi dictionary. Kalau ketemu hurufnya, ganti!

# ...kode sebelumnya...

# 3. Loop & Replace
for huruf_lama, huruf_baru in kamus.items():
    password = password.replace(huruf_lama, huruf_baru)

# 4. Output Hasil
print("Password Kuat: " + password)

Note: .replace() itu cara cepat Python untuk mengganti tulisan.

RESULT

> --- PASSWORD MAKER ---
> Masukkan kata: basoka
> Password Kuat: b@$0k@
