# Alternate UI Experiment

> **Fungsi dokumen:** menjelaskan tujuan dan status eksperimen tampilan alternatif Student Dashboard.
>
> **Status:** eksperimen; bukan versi produksi.

Folder ini mempertahankan lima halaman perjalanan siswa sebagai area eksplorasi UI. Halaman menggunakan backend dan key penyimpanan yang sama dengan versi utama, sehingga pengujian perlu memakai data uji dengan hati-hati. Jangan mengarahkan URL publik utama ke folder ini sebelum seluruh alur dan perbedaan perilaku diaudit.
