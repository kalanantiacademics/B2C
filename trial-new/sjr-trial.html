MISSION BRIEF

RESCUE GAME 🐕

Tap karakter yang benar supaya terselamatkan. Jangan tap bom, karena game bisa gagal!

Goal 🎯

Karakter rescue bergerak terus dan hilang sementara saat berhasil ditap.

Avoid 💣

Tambahkan bom / karakter salah. Kalau ditap, game gagal atau bereaksi sedih.

Tebak Logika Game

"Jika kita tap karakter yang benar, maka..."

Step 1: Karakter Rescue Bergerak

Susun kode ini di karakter yang perlu diselamatkan:

Cari icon yang sama di palette CodeJR
YOUR CODE
Start on Flag → Move Right → Move Left → Repeat Forever

Karakter rescue akan bergerak terus supaya game terasa hidup.

Kuis Kode #1

Start on Flag

Apa fungsi block Start on Flag?

Kuis Kode #2

Block mana yang membuat karakter bereaksi saat kita tap?

Start on Tap

Kuis Kode #3

Setelah berhasil ditap, block mana yang membuat karakter hilang?

Step 2: Saat Karakter Rescue Ditap

Tambahkan kode kedua ini di karakter yang perlu diselamatkan:

Cari icon yang sama di palette CodeJR
YOUR CODE
Start on Tap → Pop Sound → Hop → Hide → Wait → Show

Saat ditap, karakter bersuara, hop, hilang sebentar, lalu muncul lagi.

Step 3: Tambah Bom / Karakter Salah

Susun kode ini di sprite Bom atau karakter yang tidak boleh ditap:

Kalau bom ditap, game gagal / reaksi sedih
YOUR CODE
Start on Tap → Pop Sound → Stop

Ini membuat anak paham tap benar dan tap salah punya akibat berbeda.
